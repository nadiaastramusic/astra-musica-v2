🔥 Firebase Storage Setup

To make images permanent, connect your Firebase project:

  1. Go to Firebase Console
  2. Select your project → Storage → Get Started
  3. Set rules to allow reads: allow read;
  4. Upload your logo → Copy the download URL
  5. Paste the URL in "Logo URL" field above

For now, uploaded images work for the current session. They reset when the server restarts.
